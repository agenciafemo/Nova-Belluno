# Publicações oficiais da Nova Belluno

Estas imagens são cópias locais das miniaturas públicas exibidas no perfil
oficial `@novabelluno`. Cada imagem deve permanecer vinculada à publicação
original no Instagram e ser atualizada quando o grid editorial for renovado.

Captura editorial: 26 de agosto de 2026.

As variantes `*-400.webp`, `*-640.webp` e `*-960.webp` são derivadas das
miniaturas locais para atender diferentes densidades de tela. Para obter
mais detalhe real no futuro, substitua a fonte por exports originais do
Instagram em 1080 px ou maiores; a variante de 960 px não inventa detalhes
que não existiam na captura original.
